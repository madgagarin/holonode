# Политика безопасности

## Сообщения об уязвимостях

Если вы обнаружили потенциальную уязвимость в Worker SDK, пожалуйста, не открывайте публичное Issue. Вместо этого отправьте письмо на адрес madgagarin@gmail.com.

## Модель безопасности

Worker SDK является ключевым исполнительным узлом в **Холархической Логической Сети (HLN)** и экосистеме Holarchy, спроектированным по принципам Zero Trust:

1. **Mutual TLS (mTLS)**: Поддержка клиентских сертификатов для защищенного и аутентифицированного взаимодействия с оркестратором.
2. **Динамическая ротация токенов**: Автоматическое обновление STS-токенов доступа без необходимости перезапуска воркера.
3. **Строгая изоляция**: Каждая задача выполняется в собственной изолированной временной директории (`TASK_FILES_DIR`). Данные одной задачи недоступны для другой.
4. **Защита от Path Traversal**: Строгий контроль путей файлов с предотвращением выхода за пределы рабочей директории задачи.
5. **Автоматическая очистка**: Временные данные задачи и файлы `.tmp_*` удаляются сразу после завершения или сбоя задачи, предотвращая накопление данных.
6. **Защита конфиденциальных данных**: Ключи доступа S3 и токены передаются только через переменные окружения или защищенные объекты конфигурации и никогда не логируются.
7. **Целостность сообщений (HMAC-SHA256)**: Воркер автоматически подписывает все исходящие сообщения (хартбиты, результаты, события) своим токеном, предотвращая подмену данных.
8. **Проверка подписи входящих задач**: Верификация криптографической подписи HMAC-SHA256 (`sig` / `orchestrator_signature`) входящих задач с использованием `ORCHESTRATOR_SECRET_KEY`.
9. **Контроль политик выполнения**: Проверка соответствия входящих задач списку разрешенных навыков (`allowed_skills`).
10. **Защита от атак повтора (Replay Protection)**: Все подписанные сообщения содержат временную метку (`timestamp`). Оркестратор отклоняет любые устаревшие пакеты.

Смотрите полную [Модель безопасности RXON / HLN](https://github.com/madgagarin/rxon/blob/main/SECURITY.md) и [Политику безопасности Holarchy](https://github.com/madgagarin/holarchy/blob/main/SECURITY.md) для получения подробной информации об экосистеме.
